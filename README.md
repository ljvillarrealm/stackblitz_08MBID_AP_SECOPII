# SECOP II · Anatomía de la contratación pública en Colombia

Trabajo final de la asignatura **Visualización de datos** (Máster Big Data & BI).

## Pregunta de investigación
> ¿La contratación pública en Colombia se reparte de forma equilibrada entre entidades y territorios, o se concentra en unos pocos compradores?

## Dataset
**SECOP II – Procesos de Contratación**, Datos Abiertos Colombia.  
URL: https://www.datos.gov.co/Estad-sticas-Nacionales/SECOP-II-Procesos-de-Contrataci-n/p6dx-8zbt

## Herramientas utilizadas
1. **Datawrapper** — mapas y gráficos editoriales.
2. **Looker Studio** (Google Data Studio) — dashboard interactivo.
3. **Google Sheets** — limpieza y agregación previa.

## Cómo ejecutar en StackBlitz
1. Crear un nuevo proyecto **Static** en https://stackblitz.com
2. Subir `index.html`, `styles.css` y `package.json`.
3. El proyecto sirve directamente como sitio estático.

## Cómo exportar a PDF
Desde el navegador → **Imprimir** → **Guardar como PDF** (los estilos `@media print` están optimizados para esa salida).
